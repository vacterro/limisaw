# LIMISAW

**ファイル1つ。ランタイム不要。すべてのAIエージェント制限をトレイに。**

[English](README.md) · [Eesti](README.ee.md) · [Eesti (lihtne)](README.ded.md) · **日本語**

LIMISAWは、**Codex、Claude Code、Antigravity、Zcode**のクォータ残量を表示するWindowsトレイモニターです — 各ベンダーが公開しているすべてのアカウント単位で。各ベンダーに、ベンダー自身がすでに知っている数値を、そのベンダー独自の読み取り専用呼び出しで尋ねるため、**クォータを読むためにクォータは一切消費されません**。`auth.json` をパースせず、プロンプトを送信せず、自発的に何かをインストールすることもありません。

**`LIMISAW.exe` を[Releases](https://github.com/vacterro/limisaw/releases)からダウンロード — それがインストールの全部です。** 最新：**v0.0.10**。全パレット、両方のアラート音、アイコンが中に入っています。空のフォルダに置いて実行してください。

```
LIMISAW.exe          <- Releasesから、これがインストールの全部
LIMISAW.ini          <- 初回起動時にexeの隣に書き込まれます
```

## 何を読むか

| ベンダー | ソース | ウィンドウ |
| --- | --- | --- |
| **Codex** | `codex app-server` JSON-RPC `account/rateLimits/read`、`CODEX_HOME` ごとに1回 | 5時間、週次、月次（Freeプラン）、 plus プランが持つリザーブプール |
| **Claude Code** | `claude -p "/usage"`（0ターン、$0.00）plus ステータスラインキャッシュ、Claude Desktopの使用量サンプラー、Claude Codeの拒否ジャーナルをフォールバックとして | 5時間、週次、モデル別週次 |
| **Antigravity** | `agy -p "/usage" --output-format json` plus IDEの429ジャーナル | 週次**および**5時間、**モデルプールごと**（Gemini / Claude & GPT） |
| **Zcode** | `GET /api/monitor/usage/quota/limit` — アプリ自身が使うのと同じmonitorエンドポイント、`api.z.ai` または `open.bigmodel.cn` | 5時間、週次（GLM Coding Plan） |

**読み取りは無料です。** どれもベンダー独自の「教えて、実行はしない」呼び出し — readメソッド、またはCLIがローカルで応答するスラッシュコマンド、またはmonitorエンドポイント。想定ではなく測定済み：Claudeは `num_turns: 0` と `$0.00` を報告し、6回連続のZcode読み取りでカウンターは同一のままでした。テストがソースに対してこれを保証するので、後から誰かがプローブを「改善」してモデルに残クォータを尋ねさせることはできません。

**バンクされたリセット。** Codexは、消費したウィンドウをオンデマンドで再充填する一回限りのクレジットを付与します。カードは何があり、いつ期限切れになるかを表示 — `banked: Full reset (Weekly + 5 hr)  expires in 29d` — そして `Use reset` ボタンが1つを使いますが、正確なコマンド（`account/rateLimitResetCredit/consume`）を名指しし、取り消せないことを告げるダイアログの後でのみです。これはLIMISAWの中でベンダー側の何かを変える唯一のもので、決して暗黙的には起きません。

**発見される、ハードコードされない。** 各ベンダーが公開するすべてのアカウントがカード、トレイの読み取り、メニュー行になります — 新しいログインにコード変更は不要です。`~/.codex`、`~/.codex-account2`、`~/.codex-何でも`：すべて自動で。リザーブプールを持つプランは、そのプールのベンダー自身の名前でラベル付けされた独自の行を得ます。

**プール対応ゲーティング。** 消費された長いウィンドウは*自分自身のクォータプール内だけ*で短いウィンドウをゼロにします。枯渇したClaude/GPT週次がGeminiの5時間ウィンドウを偽装死させず、消費されたCodex週次が `gpt-reserve` を偽装死させません。カードは `locked by <window>` と表示します。Antigravityの `disabled` 5時間バケットは本物のウィンドウとして保持されます — プールが消費されていれば0%にゲートされ、そうでなければ `--` — 100%空きとしては読まれません。

**失敗したスイープはカードを消さない。** 一度失敗したベンダーCLIは、クォータのないベンダーではありません。最後の正常な数値が残り、薄めて `last good HH:MM:SS` とタグ付けされ、*なぜ*古いかを一行で示します — ベンダー自身の言葉で。「Not logged in」は直せるものとして読めます。

**経過したウィンドウは満杯。** ウィンドウ自身のリセット時刻が過ぎたら、即座に100%と読みます — 時計がすでに証明済み；プローブ不要。

## Zcodeには1行の許可が必要

Zcodeはここで唯一CLIのないベンダーです：Electronデスクトップアプリで、PATHに何も置きません。クォータにはAPIキーが必要で、**他のアプリの設定ファイルにあるキーはLIMISAWのものではありません**。入り口は正確に2つ：

```powershell
$env:ZAI_API_KEY = "..."        # すぐ動く、スイッチ不要
```

```ini
; LIMISAW.ini — Zcode自身の設定からキーを読むことを許可
ZcodeReadConfig=1
```

どちらもなければ、Zcodeカードは待機し、2つの選択肢を表示します — 何も読みません。どちらかあれば、LIMISAWは2つの固定ホストのうち1つに**1回のGET**を送り、リダイレクトを拒否してキーが他へ転送されないようにし、1つのファイルから正確に1つのフィールドを読み、カードやログに届きうるメッセージからキーを削除します。

## トレイ

- **4つのレイアウト** — 数字1つ、2段重ね（最悪の短期を最悪の長期の上に）、読み取りごとに1本のバー、1x1/2x2/3x3グリッドの読み取りごとに1セル — × **4つのフィル粒度**（半分、4分、8分、ピクセル単位）。
- **表示内容はあなたが選びます。** 4ベンダーの十二のウィンドウは16ピクセルのアイコンに収まらないので、`Tray` タブが見つかった全読み取りをライブ値とともに一覧し、並べ替え（**行をドラッグ**または矢印）、非表示、アイコンに届く数の上限（1-9）を設定できます。上限を超えた行は隠されるのではなく薄く表示されます。新しい読み取りはデフォルトで表示 — 新しいログインを黙って隠すのはベンダーの故障に見えます。
- **ホバーでテーマ付きパネル**：読み取りごとに1行と専用ゲージ、アカウントごとにグループ化、トレイ選択外の読み取りは薄く。シェルのツールチップは63文字の1行で、10の読み取りは運べません。
- **カウントダウン**：`Tray shows: Off / % / Time`。`Time` はそのウィンドウ自身のリセットまでの待ち時間をアイコンに — `12m`、`3h`、`2d`。不明または過去の刻印は `--`、決して `0m` ではありません。
- **ピクセルアート、常に。** トレイアイコンは16x16グリッドに描かれ、整数ピクセルでのみ拡大縮小；アプリアイコンはシェルが要求するすべてのサイズの実フレームを持ち、シェル自身のローダーで読み込まれます。Windowsのスムージングに任せるものは何もありません。
- **シングル左クリック**でウィンドウ、右クリックでメニュー — アクティブテーマで描かれ、システムの白ではありません。

## アラート

各アラートは**2つのスイッチ** — バルーンと音 — 片方を消して片方を残すのは現実の好みだから：

- **再充填時**：ウィンドウがリセットされたときのバルーンおよび/またはチャイム（同梱 `success_powerup.wav`）。
- **N%で低アラート**：ウィンドウがしきい値に落ちた**最初**のバルーンおよび/またはチャイム（同梱 `pop_cartoon_pop.wav`）。リセットサイクルごとにウィンドウ1回だけ、うるさくない：起動後の最初のスイープはすでに低いものを記録するだけ、低いままのウィンドウは更新のたびに再アラートせず、消費に応じてリセット時刻がずれる*ローリング*ウィンドウは新しいサイクルと誤認されません。しきい値は**イベントのもの**なので、どちらのチャネルでも生きます。
- すべてに共通の**音量**（Windowsには音ごとの音量がないため、WAVのサンプルをキャッシュコピーにスケール）、自分のWAVライブラリ用のフォルダ選択、イベントごとの `WAV` ボタン、アラートがオフでも実音量でプレビューする `Play` ボタン。
- 音量としきい値は**ドラッグスライダー** — レールを押してジャンプ、ドラッグでスクラブ。音量の出荷時は5%。

## ウィンドウ

4つのタブ（`Accounts`、`Tray`、`Settings`、`CLIs`；キー `1`-`4`）がトレイメニューの全設定を、`TRAY ICON`、`ALERTS`、`APP` の3ラベルグループで運びます。

- **すべてが自分を説明します。** どのコントロールでもホバーすればフッターが何をするか言います — フローティングツールチップではなくフッター。プレビュー上のツールチップは判断する対象を隠すからです。
- **意味を持ちえないコントロールは目に見えて死んでいます。** アイコンが数字だけを描く間はフィル粒度がグレーアウト；バーとセルでは数字読み出しがグレーアウト；両チャイムがオフなら音量がグレーアウト；アラートのWAVピッカーはチャイムがオンの間だけ現れ、低しきい値は両方の低チャネルがオフのときだけグレーアウト。それぞれ理由を言います。
- **プレビューは意図的に偽物**、専用のクォータスライダー付き：アカウントがそこまで行くのを待たずに、任意のレイアウトを5%と90%で判断できます。本物のトレイ経路で描画されるので、アイコンと食い違いようがありません。
- **ドラッグで並べ替え** — `Tray` タブのトレイ読み取り、`Accounts` のアカウントカード。
- **アカウントの可視性** — 各カードの `x` はそのアカウントを `Accounts` タブから隠します；Settingsは全アカウントを `hidden`/`shown` トグル付きで一覧。2つの表示フィルターがフリート全体にも同じことを：`Hide spent` は全ウィンドウが0%のアカウントを隠し、`Only 5h` は今すぐ使える5hウィンドウを持つアカウントを残します。3つとも**表示のみ**：スイープはどのみち全アカウントをプローブするので、隠されたりフィルターされたりしたアカウントはクォータが戻った瞬間に自力で戻ります — モニタリングをやめたモニターはモニターではありません。
- **右ドラッグでウィンドウ移動**（左ボタンが全コントロールを所有）、`Alt+A` で**常に手前に**ピン留め — 永続化されるので、作業領域に浮かせたモニターは再起動後も浮いたまま。
- **Used/Left**：1つのボタン（または `U`）が全パーセントを残量と消費の間で反転 — **バーの満たされる向きも逆になります**、枯渇したアカウントは空ではなく `100%` 使用済みの満杯バーとして読めます。色は常に*残り*について警告します。
- **テーマ**：16のWintageパレットを内蔵；`T` で循環。
- `F5` 更新、`U` used/left、`T` テーマ、`Alt+A` 手前、`1`-`4` タブ、右長押しで移動、`Esc` 非表示。ウィンドウは**コンテンツに合わせて成長** — ジェスチャーの後ろに列を隠すスクロールバーはありません。
- **Start with Windows** はトレイに静かに起動；2回目の起動は2つ目のアイコンを追加する代わりに既存のインスタンスをアクティブにします。
- **Install CLIs** は各ベンダー独自の公開インストールコマンド、発行者、ターゲットパスを表示し、明示的な確認の後にだけ、可視コンソールで実行します。リモートスクリプトのシェルへのパイプは決して暗黙ではありません。

## 再ビルドなしでのカスタマイズ

exeの隣のファイルは埋め込みコピーに**勝ちます**：

- `Themes\mine.json` はパレットを追加；`Themes\goldendefault.json` は内蔵のものを置き換え。
- exeの隣の `Sounds\` がサウンドライブラリになります（同梱WAVは今も名前で解決）。
- exeの隣の `heh.ico` がアプリアイコンを置き換え。
- `LIMISAW.ini` が全設定をプレーンテキストで保持。

## ビルド

Windowsは必要なコンパイラを同梱しています。インストール不要：

```powershell
pwsh .\build.ps1            # -> LIMISAW.exe
pwsh .\build.ps1 -Tests     # ビルド + テストスイート全体を実行
```

`tests\` は34ハーネス / 約6300アサーション：クォータのルールと「読むコストはゼロ」契約（`limits.cs`）、設定パネル固有のルール（`settings_ux.cs`）、単一ファイルの主張（`standalone.cs`）、トレイ描画のピクセル純度、ウィンドウレイアウト、アラートのタイミング、キャリーフォワード、ゲーティング、ツールチップとトレイ項目ピッカー、安定した読み取り識別（`metric_identity.cs`）、不明対ゼロのクォータ（`unknown_quota.cs`）、実際のプロセスツリーによるスポーンプロセス封じ込め（`child_job.cs`）、バッチシムCLI起動（`cmd_shim.cs`）、アカウント可視性フィルターとウィンドウコントロール（`accounts_visibility.cs`）、 plus ソースごとの読み取り予算 — Codex app-serverセッションプール、AntigravityとClaudeのジャーナルスキャン、INI読み書きパス、描画パスのネイティブリソース寿命（`gdi_paint.cs`）。

`tools\make_ico.cs` はアートが変わったとき、シェルが要求する各サイズに1つのポイントサンプリングフレームで `heh.ico` を再生成します。
